Let's get you unstuck.

Email support@ringlochid.me for help, feedback, privacy questions or a private security report.

For a useful bug report

  1. Tell us your browser, operating system and LeoTabs version.
  2. Describe what you expected and what happened.
  3. List the smallest steps that reproduce it, using sample tabs if possible.
  4. Include a screenshot only if it helps, and check it for personal information first.

Please don't send API keys, passwords, a browser profile or a full browsing backup. For security issues, use the subject LeoTabs security report and keep the report private while it is investigated.

Independent, and still growing

LeoTabs is made by Leo (ringlochid). There is no guaranteed response time or paid support service today. Core features work without a LeoTabs account. Future optional server-backed plans will be described before they launch.

Source and contributions

The repository is being prepared for public access after the first Chrome Web Store release is live. Source is licensed under MPL-2.0. Contributions, bug reports and documentation improvements are welcome.
