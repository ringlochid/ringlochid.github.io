Your library

Use spaces to separate areas of your life or work, and collections to save a task you want to return to.

On this page

Spaces

Use the plus beside the space names to add a space. Select a space to see its collections. Rename a space inline; Enter saves and Escape cancels.

Drag a space name left or right. The insertion bar shows where it will land. Its menu also offers Move left and Move right, so dragging is not required. Undo can reverse a move.

The space menu's Remove workspace action uses the older word “workspace” for a space. It deletes that space and its saved collections, links and notes; open browser tabs stay open. Move collections to another space first if you want to keep them. If you remove the last space, a new empty one is created. Read the displayed counts before confirming.

Collections

Choose New collection to start an empty one, or save open tabs. Rename a collection inline. Use its menu to pin/unpin it, move it to another space, duplicate it, open it in a new window, view previous versions, group and sort, organise with AI, export or delete it.

Drag a collection header to reorder it. Watch the insertion bar before dropping. Pinning a collection keeps it easy to find; it is separate from pinning a browser tab.

The board/list buttons change how collections are displayed. The collection chevron folds it, and the expand button focuses that collection; Restore returns to the board. Show more reveals links hidden by the preview limit. A short preview does not mean links were deleted.

Links, groups and notes

Use Add link to save a URL manually. Each link can have a title and note. Clicking a saved link opens a fresh browser tab, including when found through search.

Use Add group, a group menu, selection actions or dragging to organise related saved links. The groups guide explains the difference between saved groups and live browser groups.

A collection note records what you were doing and what comes next. Edit the note in the collection; use Delete note to remove it. A small note indicator on a link can be hovered or focused to read, or clicked to keep the note visible.

Colours and the current collection

Choose a collection colour from its options, including a custom colour. When a collection is active, its colour appears in the current-collection controls and lion icons. With no active collection, the lion uses its default amber colour.

Viewing a space or expanding a collection does not by itself make that collection current in your window. Use Switch to do that. See saving and switching for Auto-update.

Deleting a saved item can leave older recovery copies. For recovery and data removal, see Undo and recovery and Settings and privacy.
