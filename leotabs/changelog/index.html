Preparing for the first store release

0.13.0 · development version

This is the current development version, not an announcement of a previous Web Store release.

  • LeoTabs name and a lion that takes on your active collection's colour.
  • Reorderable spaces, with insertion feedback and Undo.
  • Improved AI response handling and switcher Alt-key behaviour.
  • Alt + Shift + Q to open the library.
  • Backup JSON and optional whole-library Notion export.

Launch preparation

New privacy disclosures, visible controls for automatic previews, removal of redundant legacy API keys, and documentation for permissions, support and contribution.

There is no paid LeoTabs plan today. Optional future features needing servers may introduce paid plans with pricing and data handling explained before launch.
